# RHTrevo

Plataforma privada de gestão de pessoas, operação, tarefas, processos e desenvolvimento do Grupo Trevo.

## Estado inicial

O projeto está sendo reconstruído a partir da especificação funcional e das decisões de produto consolidadas em [`docs/`](docs/).

A primeira entrega estabelece a fundação administrativa: estrutura organizacional editável, vínculos de pessoas, permissões individuais por escopo, dados sensíveis controlados, organograma configurável e auditoria.

## Princípios

- A plataforma é a experiência operacional principal; G4 OS é uma camada opcional para usuários autorizados.
- Acesso é negado por padrão e concedido por usuário, ação e escopo; cargo não cria permissão implícita.
- Dados produtivos só serão migrados após validação funcional e de segurança.
- O ambiente inicial é privado e restrito ao administrador raiz.
